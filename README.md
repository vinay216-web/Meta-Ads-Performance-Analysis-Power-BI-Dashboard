# Meta-Ads-Performance-Analysis-Power-BI-Dashboard

📌 Project Overview

This project focuses on analyzing Meta Ads advertising performance through an interactive Power BI dashboard.

The dashboard provides insights into advertising impressions, clicks, shares, comments, purchases, engagement, and conversion performance.

The main objective is to monitor campaign performance and understand how different advertising types, demographics, and geographical locations contribute to overall engagement and advertising results.

🎯 Project Objectives

- Analyze overall advertising performance.
- Monitor impressions, clicks, shares, comments, and purchases.
- Evaluate Click-Through Rate (CTR) and conversion performance.
- Analyze audience engagement by age and gender.
- Understand advertising performance across different countries.
- Compare different advertising formats.
- Identify weekly and hourly performance trends.
- Create an interactive dashboard for better decision-making.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Modeling

 📊 Key Performance Indicators (KPIs)

The dashboard tracks the following metrics:

| KPI | Description |
|---|---|
| Impressions | Number of times ads were displayed |
| Clicks | Number of clicks on advertisements |
| Shares | Number of times advertisements were shared |
| Comments | Number of comments received |
| Purchases | Number of purchases recorded |
| CTR | Click-Through Rate |
| Engagement Rate | Measures audience interaction |
| Purchase Rate | Purchase performance |
| Conversion Rate | Measures conversion performance |
| Total Budget | Total advertising budget |
| Average Budget per Campaign | Average campaign budget |

**📈 Dashboard Features**

Displays important advertising performance indicators using interactive KPI cards.

## 📈 Dashboard Features

### 1. KPI Overview
Displays important advertising performance indicators using interactive KPI cards.

### 2. Demographic Analysis
Analyzes audience engagement and impressions by:
- Gender
- Age groups

### 3. Geographical Analysis
Visualizes advertising engagement and impressions across different countries.

### 4. Trend Analysis
Includes:
- Weekly performance trends
- Hourly performance trends

### 5. Advertising Type Analysis
Compares the performance of different advertising formats:
- Image Ads
- Video Ads
- Carousel Ads
- Stories Ads

### 6. Interactive Filters
The dashboard includes:
- Dynamic metric selection
- Campaign name filter
- Target interests filter
- Month-based analysis

## 💡 Business Questions

This dashboard helps answer questions such as:

1. How many impressions and clicks were generated?
2. Which age group shows the highest engagement?
3. Which gender contributes more to audience engagement?
4. Which countries generate higher engagement?
5. Which advertising format performs better?
6. How does advertising performance change over time?
7. How do campaign metrics change when different filters are applied?
